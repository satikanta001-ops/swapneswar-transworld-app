Import & Export Data

Export downloads everything (all circles, employees, challans, i3ms, principals, etc.) as one JSON backup file. Import merges that file in by record ID — nothing existing gets deleted, matching records get updated, new ones get added. Useful for bringing offline data entry (from "Offline Mode" on the login screen) into the live database: export on the offline device, then import that file here while signed into Live mode.
